# Customer Analytics API

## Опис проекту
Цей проект — це Machine Learning мікросервіс для предиктивної аналітики клієнтів. Він прогнозує ймовірність відтоку (Churn) та виконує сегментацію користувачів на основі їхніх характеристик. Проект демонструє повний цикл MLOps: від підготовки даних та навчання моделей до розгортання через REST API з налаштованим CI/CD та структурованим логуванням.

## Стек технологій
* **Backend:** FastAPI, Pydantic, Python 3.10
* **Machine Learning:** Scikit-Learn (RandomForest, KMeans), Pandas, Joblib
* **DevOps & MLOps:** Docker, GitHub Actions, Custom JSON Observability

## Що було реалізовано (Features)
* **Пайплайн даних:** Написано ООП-класи для підготовки даних (StandardScaler) з метою уникнення витоку даних (data leakage) під час роботи API.
* **Навчання моделей:** Використано ансамблеві методи (Random Forest) для класифікації відтоку клієнтів, а також алгоритм K-Means для розбиття клієнтської бази на 3 сегменти.
* **REST API:** Інференс моделей загорнуто у швидкий веб-сервер FastAPI. Реалізовано сувору типізацію та валідацію вхідних даних клієнта за допомогою Pydantic.
* **Observability (Моніторинг):** Налаштовано кастомний логер, який перехоплює вхідні запити, результати прогнозів та час виконання, зберігаючи їх у структурованому форматі JSON.
* **CI/CD та Контейнеризація:** Додано `Dockerfile` для повної ізоляції середовища. Налаштовано GitHub Actions для автоматичної перевірки збірки контейнера при кожному коміті в репозиторій.

## Як запустити локально

1. Клонуйте репозиторій та перейдіть у робочу директорію:
git clone https://github.com/ignat4/customer_analytics_api.git
cd customer_analytics

2. Зберіть Docker-образ (переконайтеся, що Docker Desktop запущено):
docker build -t ml-api .

3. Запустіть контейнер:
docker run -p 8000:8000 ml-api

4. Протестуйте API через вбудовану документацію:
Відкрийте у браузері 👉 http://localhost:8000/docs
Перейдіть до маршруту `POST /predict`, натисніть "Try it out" та надішліть тестові дані клієнта у форматі JSON.
